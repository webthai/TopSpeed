# Trip Tracker

เว็บแอปคนเดียว ไม่ต้อง login เก็บพิกัด GPS + ความเร็วอัตโนมัติระหว่างทริป บันทึกลงเครื่องก่อน (ใช้งานออฟไลน์ได้) แล้วซิงก์ขึ้น Google Sheets เมื่อกดจบทริปและมีเน็ต

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (UI + logic + IndexedDB) |
| `manifest.json` | ทำให้ติดตั้งเป็น PWA บนหน้าจอโฮมได้ |
| `sw.js` | Service worker แคช app-shell ไว้ใช้ออฟไลน์ |
| `icon-192.png`, `icon-512.png` | ไอคอนแอป |
| `apps-script.gs` | โค้ด backend สำหรับ Google Apps Script (เขียนข้อมูลลง Sheets) |

## ติดตั้งใช้งาน

### 1. เตรียม Google Sheets backend
1. สร้าง Google Sheet ใหม่
2. เมนู **Extensions → Apps Script** วางโค้ดทั้งหมดจาก `apps-script.gs`
3. รันฟังก์ชัน `setup()` หนึ่งครั้ง (เมนู Run) — จะสร้างชีต `Trips` และ `TrackPoints` พร้อมหัวตาราง ครั้งแรกต้องกด Allow เพื่อขอสิทธิ์
4. **Deploy → New deployment** เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอก Web app URL (ลงท้ายด้วย `/exec`)

### 2. โฮสต์ไฟล์เว็บแอป
ต้องเสิร์ฟไฟล์ทั้งหมดนี้ผ่าน HTTPS ด้วยกัน (ในโฟลเดอร์เดียวกัน) เพราะ:
- GPS (`navigator.geolocation`) ต้องใช้ HTTPS หรือ `localhost`
- Service worker ต้องใช้ HTTPS หรือ `localhost`

วิธีที่ง่ายที่สุด: อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages, Netlify, Vercel, หรือ Firebase Hosting (ฟรีทั้งหมด) — ลากทั้งโฟลเดอร์วางแล้วได้ URL ทันที

### 3. ตั้งค่าในแอป
1. เปิดแอปในมือถือ (Safari/Chrome)
2. กดไอคอนเฟือง (มุมขวาบน) → วาง Web app URL จากขั้นตอนที่ 1 → บันทึก
3. (แนะนำ) กด "เพิ่มลงหน้าจอโฮม" จากเมนูเบราว์เซอร์ เพื่อใช้งานแบบแอปเต็มจอ

## การใช้งาน

- กด **เริ่มทริป** → แอปจดพิกัดทุก ~2-3 วินาทีอัตโนมัติ เก็บใน IndexedDB ในเครื่อง (ไม่ต้องมีเน็ต)
- กด **จบทริป & บันทึก** → คำนวณสรุประยะทาง ความเร็วเฉลี่ย/สูงสุด และตารางต่อกิโลเมตร
- ถ้าลืมปิดแอปหรือเน็ตหลุดกลางทาง ข้อมูลยังอยู่ในเครื่อง กลับมาเปิดแอปใหม่แล้วกด **ซิงก์** ในหน้ารายละเอียดทริปได้ทีหลัง
- หน้า **ประวัติ** แสดงทริปทั้งหมด กดเข้าไปดูกราฟความเร็ว-ระยะทาง + แผนที่เส้นทางไล่สี (เขียว=ช้า, แดง=เร็ว) + ตารางต่อกม.
- **หมายเหตุ:** ดูแผนที่ย้อนหลังครั้งแรกต้องมีเน็ต (โหลด tile จาก OpenStreetMap) — ส่วนกราฟความเร็วดูได้แม้ออฟไลน์
- ในหน้ารายละเอียดทริป มีปุ่ม **"ดาวน์โหลดแผนที่ไว้ดูออฟไลน์"** กดครั้งเดียวตอนมีเน็ต แอปจะโหลดและแคช tile ของแผนที่บริเวณเส้นทางไว้ในเครื่อง (ผ่าน Service Worker) ครั้งต่อไปแผนที่จะขึ้นเร็วขึ้นมากและดูได้แม้ไม่มีเน็ต — ไม่ต้องกดก็ได้ เพราะทุก tile ที่เคยเห็นแล้วจะถูกแคชอัตโนมัติอยู่แล้ว ปุ่มนี้แค่ช่วยดาวน์โหลดล่วงหน้าทั้งหมดทีเดียว
- **หมุดบนแผนที่:** จุดเริ่ม (🟢) และจุดจบ (🏁) ของเส้นทางปักให้อัตโนมัติ พร้อม popup บอกว่า "ต้นทาง"/"ปลายทาง" — แตะจุดไหนก็ได้บนแผนที่เพื่อปักหมุดเอง (📍) เช่นระบุปลายทางจริงหรือจุดพัก ตั้งชื่อหมุดได้ แตะหมุดที่ปักไว้แล้วเพื่อลบ

## Google Sheets Sync — ตอนนี้ตั้งค่าไว้ให้แล้ว + ซิงก์อัตโนมัติ

URL ของ Google Apps Script ถูกฝังไว้เป็นค่าเริ่มต้นในโค้ดแล้ว (ไม่ต้องกรอกเองอีก) และแอปจะซิงก์ให้อัตโนมัติ:
- **ทันทีที่กด "จบทริป & บันทึก"** ถ้าตอนนั้นมีเน็ต แอปจะซิงก์ขึ้นชีตให้เองแบบเงียบๆ ในพื้นหลัง
- **ทุกครั้งที่เปิดแอป** จะเช็คว่ามีทริปที่ "รอซิงก์" ค้างอยู่ไหม (เช่นตอนบันทึกไม่มีเน็ต) แล้วลองซิงก์ให้อัตโนมัติถ้าตอนนี้มีเน็ตแล้ว
- ปุ่ม "ซิงก์ขึ้น Google Sheets" ในหน้ารายละเอียดทริปยังใช้ได้ปกติ สำหรับซิงก์ซ้ำด้วยตนเอง
- ถ้าเปลี่ยนไป deploy Apps Script URL ใหม่ ให้เข้าไปแก้ในหน้าตั้งค่า (ไอคอนเฟือง) ได้เหมือนเดิม — ค่าที่กรอกเองจะ override ค่าเริ่มต้นในโค้ด

## ล็อกแอปด้วยรหัส PIN

กดไอคอนเฟือง (ตั้งค่า) → เลื่อนลงมาส่วน "ล็อกแอปด้วยรหัส PIN" → กด **"ตั้ง/เปลี่ยนรหัส PIN"** ตั้งรหัส 4 หลัก 2 ครั้งเพื่อยืนยัน จากนั้นทุกครั้งที่เปิดแอปจะต้องกรอกรหัสนี้ก่อนถึงจะเห็นข้อมูลทริป

- **ลืมรหัส:** ที่หน้าจอล็อก มีลิงก์ "ลืม?" กดแล้วยืนยันเพื่อล้างรหัสทิ้ง (ข้อมูลทริปยังอยู่ครบ แค่ปิดการล็อก ต้องตั้งรหัสใหม่เอง)
- **ปิดการล็อก:** เข้าไปที่ตั้งค่า → กด "ปิดการล็อก"
- **ข้อควรรู้:** นี่คือรหัสล็อกระดับเบราว์เซอร์/อุปกรณ์นี้เท่านั้น (เก็บใน localStorage) ไม่ใช่ระบบบัญชีผู้ใช้จริงที่มีการยืนยันตัวตนผ่านเซิร์ฟเวอร์ — ป้องกันคนหยิบเครื่องไปเปิดดูได้ดี แต่ไม่ใช่การเข้ารหัสข้อมูลจริงจัง (คนที่เข้าถึงไฟล์ IndexedDB ในเครื่องโดยตรงยังเห็นข้อมูลได้)

## แก้ปัญหา: ปุ่มซิงก์ค้างที่ "กำลังซิงก์..." ไม่จบ

สาเหตุที่พบบ่อยที่สุด และวิธีเช็ก:

1. **เปิด Web app URL ตรงๆ ในเบราว์เซอร์ก่อน** (วาง URL ที่ลงท้าย `/exec` ในแท็บใหม่) — ถ้า deploy ถูกต้องจะเห็น `{"ok":true,"message":"Trip Tracker backend is running."}` ถ้าเจอหน้า login ของ Google หรือหน้า error แปลว่ายังตั้งค่า deployment ไม่ถูก
2. **ต้อง redeploy ทุกครั้งที่แก้โค้ด** — แค่กด Save ในหน้า Apps Script ไม่พอ ต้องไป **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → Version: New version → Deploy** ไม่งั้น URL เดิมจะยังรันโค้ดเวอร์ชันเก่าอยู่
3. **ตรวจสิทธิ์การเข้าถึง** ต้องเป็น Execute as: **Me**, Who has access: **Anyone** (ไม่ใช่ "Anyone with Google account" เพราะแอปไม่มีระบบ login)
4. แอปตอนนี้เพิ่ม **timeout 25 วินาที** ในปุ่มซิงก์แล้ว — ถ้าเซิร์ฟเวอร์ตอบช้าเกินจะขึ้นข้อความแจ้งเตือนแทนที่จะค้างเฉยๆ ตลอดไป ลองกดซิงก์ใหม่อีกครั้งหลังอัปเดตไฟล์ `index.html`
5. โค้ด `apps-script.gs` ได้ปรับให้เร็วขึ้นแล้ว (จากเดิมลบข้อมูลทีละแถวซึ่งช้ามากถ้าทริปมีพิกัดหลายร้อยจุด เปลี่ยนเป็นเขียนทับเป็นชุดเดียว) — **ต้อง copy โค้ดใหม่ไปวางทับใน Apps Script แล้ว deploy เป็น version ใหม่ด้วย**

## ข้อจำกัดที่ควรรู้

- Browser ส่วนใหญ่จะ "พัก" GPS เมื่อแอปอยู่เบื้องหลังนานเกินไป (โดยเฉพาะ iOS Safari) — ควรเปิดหน้าจอไว้ระหว่างทริป หรือใช้โหมด "เพิ่มลงหน้าจอโฮม" ซึ่งช่วยได้บ้าง
- ระยะทางคำนวณจาก GPS point ต่อเนื่อง (Haversine) มีการกรอง jump ที่ผิดปกติ (>300 ม./จุด) ออก เพื่อลด error จากสัญญาณ GPS กระโดด
- ไม่มีระบบ login/สิทธิ์ผู้ใช้ ตามที่ตกลงไว้ — ใครมี URL ของ Apps Script ก็เขียนข้อมูลลงชีตได้ ถ้าต้องการความเป็นส่วนตัวเพิ่มเติมสามารถเพิ่ม secret token ตรวจสอบใน `doPost` ได้ภายหลัง
